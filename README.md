## راه اندازی و مدیریت آسان تانل GRE + TCP FORWARDER (Socat & HAProxy)
اسکریپت سپهر برای راه‌اندازی و مدیریت سریع و آسان تونل GRE و پورت فورارد که میتوان بین یک یا چند سرور از آن استفاده کرد، با یاد جان فدای میهن، سپهر عزیز (سپهر کجایی بابا؟)

## 🚀 نصب و اجرا

```bash
wget https://raw.githubusercontent.com/ImMohammad20000/Sepehr-GRE-FORWARDER/main/sepehr.sh && chmod +x sepehr.sh && bash sepehr.sh
```

## ✨ قابلیت‌های جدید
- **پشتیبانی از HAProxy**: امکان انتخاب بین Socat (استاندارد) و HAProxy (کارایی بالا) برای فوروارد کردن پورت‌ها.
- **مدیریت هوشمند HAProxy**: استفاده از یک پروسه واحد برای تمامی پورت‌ها جهت بهینه‌سازی مصرف منابع.
- **حذف جزئی سرویس‌ها**: امکان حذف تکی پورت‌های فوروارد شده بدون نیاز به حذف کل تانل.
- **مدیریت مجزای HAProxy**: منوی اختصاصی برای کنترل سرویس و تنظیمات HAProxy.
- **نصب اختیاری HAProxy**: نصب و حذف HAProxy به صورت مستقیم از داخل منوی اسکریپت.

## 🧭 ساختار منو
### ۱) تنظیمات سمت سرور ایران (IRAN SETUP)
در این مرحله اطلاعات سرور ایران و خارج، شماره تانل، رنج IP تانل و پورت‌های مورد نظر را وارد می‌کنید. همچنین می‌توانید روش فوروارد را بین **Socat** و **HAProxy** انتخاب کنید.

### ۲) سمت سرور خارج (KHAREJ SETUP)
تنظیمات مشابه سمت ایران را انجام می‌دهید (بدون نیاز به وارد کردن پورت). تانل GRE برقرار شده و آماده استفاده می‌شود.

### ۳) مدیریت سرویس‌ها (Services ManageMent)
مشاهده وضعیت، ری‌استارت، فعال/غیرفعال‌سازی و **حذف تکی** تانل‌های GRE و فورواردرهای Socat.

### ۴) مدیریت HAProxy (HAProxy ManageMent)
منوی اختصاصی برای مشاهده وضعیت سرویس HAProxy، مدیریت Snippetهای هر پورت و مشاهده فایل کانفیگ نهایی.

### ۵) حذف و پاکسازی (Uninstall & Clean)
حذف کامل یک تانل GRE به همراه تمامی پورت‌های فوروارد شده مرتبط با آن (Socat و HAProxy).

### ۶ و ۷) نصب و حذف HAProxy
مدیریت پکیج HAProxy به صورت مستقیم از داخل اسکریپت.

## 🛡️ لیست سرویس‌ها
برای مشاهده فایل‌های سرویس به صورت دستی:
```bash
ls -la /etc/systemd/system | grep -E 'gre[0-9]+\.service|fw-gre'
# و برای تنظیمات HAProxy
ls -la /etc/haproxy/gre-forwards/
```
